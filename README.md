# Lab 2: JSON Lab - User Profiles

## 任务要求
创建一个 JSON 文档表示用户资料，验证格式正确，并在 HTML 页面上展示。

## 文件
- `userProfiles.json` - JSON 用户数据，包含 3 个用户资料
- `index.html` - 使用 fetch API 读取并展示用户资料

## 包含字段
- firstName, lastName, email, dateOfBirth
- address: street, city, state, zipCode
- userPreferences: theme, language, notifications, subscription
